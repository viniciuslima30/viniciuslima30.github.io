## 📋 Sobre o projeto

Portfólio desenvolvido do zero, sem frameworks ou bibliotecas externas. O objetivo foi criar uma interface profissional e responsiva utilizando apenas as tecnologias fundamentais da web, demonstrando domínio de HTML semântico, CSS moderno e JavaScript vanilla.

---

## ✨ Seções

- **Hero** — apresentação com animações flutuantes
- **Sobre mim** — trajetória, formação e informações pessoais
- **Skills** — tecnologias com barras de progresso animadas
- **Projetos** — cards dos projetos desenvolvidos com links para o GitHub
- **Contato** — links diretos para email, GitHub e LinkedIn

---

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 com variáveis, Grid, Flexbox e animações
- JavaScript puro com Intersection Observer API
- Google Fonts (Playfair Display + DM Sans)
- Hospedagem via GitHub Pages

## ⚙️ Como rodar localmente

Não precisa instalar nada. Basta clonar e abrir o arquivo:

```bash
git clone https://github.com/viniciuslima30/viniciuslima30.github.io.git
cd viniciuslima30.github.io
```

Abra o `index.html` com o **Live Server** do VSCode ou direto no navegador.
